# CryoVigil Landing Page

This repository contains CryoVigil's static marketing landing page.

What is here:

- `index.html` – the main HTML entry point for the landing page
- `css/style.css` – the page styling and layout
- `assets/img/` – product and team images
- `js/` – language switching, responsive navigation, and social-sharing links
- `terms.html` – a draft Terms of Service page that requires professional legal review before publication

The page links to the Web App at `https://web-app-tst.web.app`. Provider registration, sign-in, subscription, and sales routes are configured in `index.html`. Confirm that these routes resolve to the intended views in the deployed application.

The language switcher supports English (`en_US`) and Latin American Spanish (`es_419`); English is the default. Product and team video players are present, but recordings have not been supplied and are not playable until video sources are added.

How to use it:

- Open `index.html` in a browser

The landing page is front-end only and does not include backend, database, or authentication implementation.

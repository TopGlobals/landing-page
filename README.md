# CryoVigil Landing Page

This repository contains a static landing page for CryoVigil, a product concept presented as a marketing homepage.

What is here:
- `index.html` – the main HTML entry point for the landing page
- `css/style.css` – the page styling and layout
- `assets/img/` – image assets folder for future visuals or brand graphics
- `js/` – a place for JavaScript logic if the landing page is extended later

This project is currently a front-end-only mockup. It does not include a backend, database, user authentication, or server-side logic yet.

How to use it:
- Open `index.html` in a browser

The goal of this project is to provide a quick foundation for a branded landing page that can later be expanded.
